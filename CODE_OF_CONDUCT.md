# Davranış Kuralları / Code of Conduct

Katılımcılar ve bakımcılar olarak herkes için tacizsiz bir ortam sağlamayı taahhüt ederiz. / We pledge a harassment-free experience for everyone.

- Saygılı ve yapıcı olun. / Be respectful and constructive.
- Teknik değere odaklanın. / Focus on technical merits.
- İyi niyet varsayın. / Assume good faith.

Kötüye kullanım davranışları repo sahibine bildirilebilir. / Report abusive behavior to the repository owner.

*[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) temel alınmıştır.*
