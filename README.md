# Kaydetmail

[![Backend CI](https://github.com/mtsarac/kaydetmail-mono/actions/workflows/backend-ci.yml/badge.svg)](https://github.com/mtsarac/kaydetmail-mono/actions/workflows/backend-ci.yml)
[![Frontend CI](https://github.com/mtsarac/kaydetmail-mono/actions/workflows/frontend-ci.yml/badge.svg)](https://github.com/mtsarac/kaydetmail-mono/actions/workflows/frontend-ci.yml)
[![License: AGPL-3.0](https://img.shields.io/badge/license-AGPL--3.0-blue.svg)](LICENSE)

A Turkish-language, multi-account mail client. Monorepo.

- `frontend/` - Flutter client (offline-first)
- `backend/` - .NET 10 IMAP/SMTP API (see `backend/README.md`)
- `docs/` - shared documentation

See [`AGENTS.md`](AGENTS.md) for development commands, [`CONTRIBUTING.md`](CONTRIBUTING.md) to contribute, [`SECURITY.md`](SECURITY.md) for vulnerability reporting.
