# Etiket Rehberi / Label Guide

Etiket adları İngilizce, açıklamalar Türkçedir (GitHub varsayılanları ve dependabot ile uyum için).

## Tür / Type
`bug`, `enhancement`, `documentation`, `question`, `help wanted`, `good first issue` (GitHub varsayılanları).

## Öncelik / Priority (P0 → P3)

| Etiket | Anlam |
|---|---|
| `P0` | Acil: veri kaybı, güvenlik açığı, çökme, çekirdek kullanılamaz |
| `P1` | Yüksek: planlı işi engelliyor |
| `P2` | Orta: normal |
| `P3` | Düşük: olsa iyi olur |

## Durum / Status
`status: in progress`, `status: blocked`, `status: ready to merge`, `status: wontfix`.

## Etki / Impact
`impact: security`, `impact: data-loss`, `impact: availability`, `impact: message-loss` (mail kaybı, çift gönderim, yanlış yönlendirme).

## Alan / Area
`area: frontend`, `area: backend`, `area: infra`, `area: docs`.

## Otomasyon / Automation
`dependencies`, `github_actions`, `dart`, `.NET` dependabot tarafından kullanılır.
