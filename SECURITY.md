# Güvenlik Politikası / Security Policy

## Açık bildirimi / Reporting a vulnerability

Güvenlik açıkları için herkese açık issue **açmayın**. / Do **not** open a public issue.

Özel olarak bildirin / Report privately:
[Private security advisory](https://github.com/mtsarac/kaydetmail-mono/security/advisories/new)

Lütfen şunları ekleyin / Include: etkilenen sürüm veya commit, yeniden üretme adımları, etki. Gerçek mail içeriği, token veya şifre paylaşmayın. 7 gün içinde yanıt hedeflenir. / We aim to respond within 7 days.

## Desteklenen sürümler / Supported versions

| Sürüm / Version | Destek / Supported |
|---|---|
| `main` (latest) | ✅ |
| older | ❌ (best effort) |

## Açıklama / Disclosure

Düzeltme yayımlandıktan sonra, anonimlik istenmedikçe bildiren kişi sürüm notlarında anılır. / Reporters are credited after a fix ships unless anonymity is requested.
